Quick answer: Crawlability is whether search engines can reach and fetch a page. Indexability is whether, once fetched, the page is allowed and worth adding to the index. To improve both, link to important pages internally, list them in your sitemap, avoid blocking them in robots.txt, remove accidental noindex tags, set correct canonicals and make sure key content is in the HTML.

Crawlability vs Indexability

The two words get used together, but they fail in different ways. A page can be crawlable and still not indexable, for example when it carries a noindex tag. And a page that can't be crawled can't be properly evaluated for the index at all.

How to Diagnose Problems in Search Console

Open Indexing > Pages in Google Search Console. Each excluded URL has a reason, and the reason tells you where to look.

StatusWhat It Usually MeansFirst Check
Excluded by noindex tagThe page tells Google not to index itIs the tag intentional?
Blocked by robots.txtGoogle is not allowed to crawl the URLIs the Disallow rule too broad?
Alternate page with proper canonical tagGoogle is respecting your canonicalIs the canonical pointing to the right page?
Duplicate, Google chose different canonicalGoogle disagrees with your canonicalAre the pages genuinely different?
Discovered, currently not indexedGoogle knows the URL but hasn't crawled it yetIs the page well linked internally?
Crawled, currently not indexedGoogle fetched it but decided not to index itIs the content thin or duplicated?
Not found (404)The URL no longer existsAre internal links still pointing to it?

Use the URL Inspection tool on a single page to see the last crawl date, the canonical Google selected and whether the page is on Google. After fixing a page, the same tool lets you request indexing.

Use robots.txt for Crawling, Not for Indexing

robots.txt controls which URLs crawlers may fetch. It is not a reliable way to keep a page out of Google, because a blocked URL can still be indexed if other sites link to it. To keep a page out of search results, let Google crawl it and use a noindex tag.

Do Not Block a Page You Have Noindexed

If robots.txt blocks a page, Google can't crawl it to see the noindex tag. Remove the block first, let the page be recrawled, and only then decide whether to block it.

8 Ways to Improve Crawlability and Indexability

  1. 01

    Link to Every Important Page

    Pages with no internal links, called orphan pages, are hard for Google to find and look unimportant. Link to key pages from your navigation, hub pages and related posts.

  2. 02

    Keep the Sitemap Clean

    List only live, canonical, indexable URLs. A sitemap file can hold up to 50,000 URLs or 50 MB uncompressed. Submit it in Search Console.

  3. 03

    Remove Accidental Noindex Tags

    Staging settings, SEO plugin defaults and page builders often add noindex. Check templates as well as individual pages.

  4. 04

    Set Self-Referencing Canonicals

    Every indexable page should usually point its canonical to its own preferred URL, with one consistent hostname and protocol.

  5. 05

    Fix Status Codes

    Important pages should return 200. Replace internal links to redirects and 404s with links to the final URL.

  6. 06

    Put Key Content in the HTML

    Google can render JavaScript, but many AI crawlers do not. Make sure main text and links exist in the HTML the server sends.

  7. 07

    Make Thin Pages Worth Indexing

    If Google crawls a page but won't index it, compare it with what ranks. Expand it, merge it with a similar page, or remove it.

  8. 08

    Keep the Site Fast and Stable

    Slow servers and frequent errors can reduce how much Google crawls. Fix server errors and long response times first.

Google treats the canonical tag as a strong hint rather than an order. If your canonical points to a page that doesn't match, Google may choose its own.

Questions Answered

How Long Does It Take for Google to Index a Page?

It varies from hours to weeks. Linking to the page internally, listing it in the sitemap and requesting indexing in Search Console can help, but Google decides the timing.

Why Does Google Say Crawled, Currently Not Indexed?

Google fetched the page but decided not to index it, often because it looks thin, duplicated or low value compared with other pages. Improving or consolidating the content is usually the fix.

Does Requesting Indexing Guarantee My Page Will Be Indexed?

No. It asks Google to recrawl the page sooner. Google still decides whether the page is worth indexing.

Should Every Page Be Indexed?

No. Thank-you pages, internal search results, login pages and test pages are usually better kept out of search. The goal is to index every page that is useful to searchers.
